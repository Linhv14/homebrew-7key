# 7key Homebrew tap

The [7key](https://7key.online) CLI: give AI agents and CI your secrets without showing them the values.

```bash
brew install linhv14/7key/sevenkey
```

The formula is `sevenkey` because formula names cannot start with a digit; it installs the `7key` command. Also on npm: `npm install -g @7key/cli`.
